# Immiscible SDKs

Decisions before your AI agents pay, share data or act. These are the open-source clients for [Immiscible](https://immiscible.fly.dev). The server is hosted; everything that runs in your code is here, under the MIT licence.

```shell
npx immiscible init
```

| Package | Install |
|---|---|
| [CLI](packages/immiscible-cli) | `npx immiscible init` |
| [JavaScript and TypeScript SDK](packages/immiscible-js) | `npm i @immiscible/sdk` |
| [Python SDK](packages/immiscible-py) | `pip install immiscible` |
| [Claude Code hook](packages/immiscible-claude-code) | `npm i -D @immiscible/claude-code-hook` |

Docs: https://immiscible.fly.dev/docs

Found a security issue? Please use https://immiscible.fly.dev/contact?topic=security rather than a public issue.
